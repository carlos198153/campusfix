# Superficie · CampusFix sencillo

**Modo: Operate.** El estudiante necesita hacer un reporte y leer su avance. El administrador necesita atender el conjunto, gestionar estudiantes y obtener el PDF de una semana.

La superficie utiliza navegación superior, un contenedor de hasta 1100 px y una acción principal grande **Hacer un reporte**. Las tarjetas muestran título, estado y evidencia disponible. El formulario pide pocos datos. La identidad de delfín azul se expresa mediante marca, ilustración vectorial y paleta marino/azul/cian.

El rol Estudiante ve lo propio. Los controles administrativos aparecen para el rol Administrador. La demostración anuncia su origen local y ofrece controles de rol identificados. El PIN compartido de registro se explica con claridad y no se presenta como una prueba de identidad institucional.

La revisión del 5 de noviembre separa **Arreglados** de la lista principal. Solucionar un reporte lo lleva allí; reabrirlo lo devuelve a la cola activa. Ambos roles mantienen su alcance de consulta. El registro administrador admite 5 caracteres en demo y el mínimo real de Supabase —al menos 6— cuando está conectado.

**Flujo estudiante:** acceder → hacer reporte → consultar estado.

**Flujo administrador:** acceder o crear cuenta con PIN → revisar reportes → cambiar estado → administrar estudiantes → descargar PDF semanal.

La evidencia de pruebas y revisión visual debe corresponder a esta versión; consulta `verificacion.md`. Las capturas de octubre pertenecen a la interfaz anterior.
